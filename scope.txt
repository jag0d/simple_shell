Shell Script

In the shell script, the task is to create a custom shell that supports the following commands:

    $ ls – List files in the current directory
    $ ls -l – List files in the current directory with additinal information shown
    $ cd .. – Move one directory up
    $ cd folder_name – Move to a specific directory
    $ pwd – Dsiplay current folder
    $ write |name| – Read user inputted data line by line and end when the input is just the letter q.
    $ help – Display available commands


All shell commands start with "$ " (dollar sign and a space).
