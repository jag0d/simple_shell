 Course Project

For the course project, you can choose one of three options: 

    shell script
    game 
    backend application


Shell Script

In the shell script, the task is to create a custom shell that supports the following commands:

    $ ls – List files in the current directory
    $ ls -l – List files in the current directory with additinal information shown
    $ cd .. – Move one directory up
    $ cd folder_name – Move to a specific directory
    $ pwd – Dsiplay current folder
    $ write |name| – Read user inputted data line by line and end when the input is just the letter q.
    $ help – Display available commands


All shell commands start with "$ " (dollar sign and a space).

Game

The game is a dungeon crawler where the player is created, random gear is generated from a set of items, and the player can choose what to do in his turn. Every 3 turns there is a possibility to go shopping where the player can use gold gathered from monsters and treasures. Monsters drop treasures when defeated and the player can also choose to use a chance to find treasure or defeat a monster and certainly get a treasure from the defeated monster. Periodically, for example every 5 or 10 turns a stronger monster comes, a boss, that gives better loot, upgrades the player's stats (base damage, hitpoints, giving health potions etc.) when defeated. The game ends when the player is defeated or has defeated 3 bosses. The game is text-based.

    Create a player object and his gear
    Create the enemies which stats are dependent on the amount of bosses defeated
    Create a game loop for progressing through turns and losing the game
    Create combat and treasure mechanics


Additional points can include making the shop, changing gear from the shop to the user, scoreboard saved in a file, player leveling etc.

Backend Application

In the backend application, the task is to create a project where the student can use an HTML form to create data, view the saved data at a specific route, and view more details on specific data, such as a course list or e-commerce products.

Points are earned for various routes, such as:

    Creation of data
    Deleting data
    Displaying data
    Use of custom types (structs)


This project could be something like a course listing or an e-commerce site using multiple routes and operations.

About the course project points

You earn points by implementing the required features, which differ based on the project type. Additional points can be awarded if you justify your implementations, but there is an upper limit to bonus points.
To get 20 points from the project, you must implement every listed feature. The shell project has more features listed, but they are shorter to implement. 30 points is maximum, 15 is the minimum points required and the 10 missing points can be gotten by implementing your own features. 

The course project accounts for 30% of the final grade.
